## Comment utiliser cette documentation

La plupart des scripts ont un dossier nommé **integrations**, où tu peux ajouter ton code d'intégration en bas des fichiers. La plupart du temps, tu n'auras donc besoin d'ajouter ton code que dans ces fichiers, pas dans les autres scripts.

<Tip>
  Lis attentivement les commentaires, ils expliquent tout ce dont tu as besoin juste au-dessus des lignes de code.
</Tip>

### Fichiers d'intégration

<CardGroup cols={3}>
  <Card title="cl_integrations.lua" icon="laptop">
    Code pour les scripts **côté client**, par exemple pour remplacer les notifications ou la barre de progression. C'est généralement là que tu insères le code de la catégorie `Client` de la documentation.
  </Card>

  <Card title="sh_integrations.lua" icon="arrows-left-right">
    Code qui s'exécute **à la fois côté client et côté serveur**, généralement des noms de scripts externes, que tu peux modifier si ton serveur utilise un nom différent de celui par défaut.
  </Card>

  <Card title="sv_integrations.lua" icon="server">
    Code pour les scripts **côté serveur**. C'est généralement là que tu insères le code de la catégorie `Server` de la documentation.
  </Card>
</CardGroup>

<Info>
  Si tu cherches une option que tu ne trouves pas dans la config/les paramètres normaux, elle se trouve probablement dans les fichiers d'intégration.
</Info>
