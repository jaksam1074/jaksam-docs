Dieser Bereich dokumentiert die Exports, Events und Hooks, die von jaksams Scripts bereitgestellt werden — für alle, die ein anderes Script integrieren, Standardverhalten ersetzen oder auf einem jaksam-Produkt aufbauen möchten.

Falls du stattdessen Installations-/Einrichtungsanleitungen suchst, findest du diese Inhalte im **Main**-Tab, auf der jeweiligen Home- und Installations-Seite jedes Produkts.

## Wie die Integration funktioniert

Die meisten Scripts liefern einen `integrations`-Ordner mit drei Dateien:

<CardGroup cols={3}>
  <Card title="cl_integrations.lua" icon="laptop">
    Client-seitiger Code, zum Beispiel um Benachrichtigungen oder den Fortschrittsbalken zu ersetzen. Üblicherweise der Ort, an dem du Code von einer **Client**-Referenzseite unten einfügst.
  </Card>

  <Card title="sh_integrations.lua" icon="arrows-left-right">
    Code, der sowohl client- als auch server-seitig läuft, meist Namen externer Scripts, sodass du sie auf das verweisen kannst, was dein Server tatsächlich nutzt.
  </Card>

  <Card title="sv_integrations.lua" icon="server">
    Server-seitiger Code. Üblicherweise der Ort, an dem du Code von einer **Server**-Referenzseite unten einfügst.
  </Card>
</CardGroup>

## Konventionen der Referenzseiten

Jede Export-/Event-/Hook-Seite unten folgt derselben Struktur, sodass du sie alle auf dieselbe Weise überfliegen kannst:

| Feld | Bedeutung |
|---|---|
| **Seite** | Ob es client-seitig oder server-seitig läuft. Ersichtlich daran, unter welchem Abschnitt (Client/Server) die Seite eingeordnet ist. |
| **Beschreibung** | Ein bis zwei Sätze darüber, was es tut, direkt unter dem Titel. |
| **Export/Event** | Der genaue `exports[...]:...`-Aufruf oder die `AddEventHandler`-/`RegisterNetEvent`-Signatur, in einem Codeblock. |
| **Parameter** | Eine Tabelle mit jedem Parameter, seinem Datentyp und seinem Zweck. |
| **Rückgabewert** | Eine Tabelle mit dem, was zurückgegeben wird, falls vorhanden. Wird bei Seiten weggelassen, die nichts zurückgeben. |
| **Beispiel** | Ein realistischer, funktionierender Nutzungs-Ausschnitt neben der reinen Signatur. |

<Note>
  Nicht jede Seite hat bereits einen Fehler-/Hinweise-Abschnitt. Wo Fehlerfälle oder Einschränkungen nicht dokumentiert sind, ist das eine bekannte Lücke, keine Aussage, dass nichts schiefgehen kann — schau im FAQ des jeweiligen Produkts nach oder frag im [Discord](https://discord.gg/MrXMNnvhTr), falls du auf einen nicht abgedeckten Sonderfall stößt.
</Note>
