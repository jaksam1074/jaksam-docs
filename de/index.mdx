## So benutzt du diese Dokumentation

Die meisten Scripts haben einen Ordner namens **integrations**, in dem du deinen eigenen Integrationscode am Ende der Dateien einfügen kannst. Meistens musst du deinen Code also nur in diesen Dateien einfügen, nicht in anderen Scripts.

<Tip>
  Lies die Kommentare sorgfältig durch, sie erklären alles, was du direkt über den jeweiligen Code-Zeilen brauchst.
</Tip>

### Integrationsdateien

<CardGroup cols={3}>
  <Card title="cl_integrations.lua" icon="laptop">
    Code für **client-seitige** Scripts, zum Beispiel um Benachrichtigungen oder die Progress-Bar zu ersetzen. Hier fügst du meist Code aus der `Client`-Kategorie der Dokumentation ein.
  </Card>

  <Card title="sh_integrations.lua" icon="arrows-left-right">
    Code, der **sowohl client- als auch serverseitig** läuft, meist Namen externer Scripts, die du anpassen kannst, falls dein Server andere Namen als die Standardwerte verwendet.
  </Card>

  <Card title="sv_integrations.lua" icon="server">
    Code für **server-seitige** Scripts. Hier fügst du meist Code aus der `Server`-Kategorie der Dokumentation ein.
  </Card>
</CardGroup>

<Info>
  Falls du eine Option suchst, die du nicht in den normalen Config-/Einstellungsdateien findest, steckt sie wahrscheinlich in den Integrationsdateien.
</Info>
