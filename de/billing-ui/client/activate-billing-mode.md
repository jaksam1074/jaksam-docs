---
title: "Rechnungsmodus aktivieren"
description: "Lass den Spieler einen Ziel-Spieler anklicken, um das Billing-UI-Menü zu öffnen."
icon: "hand-pointer"
---

Auslösen, um den Rechnungsmodus zu aktivieren, sodass der Spieler auf den Ziel-Spieler klicken muss und sich das Billing-UI-Menü dann öffnet.

```lua Event
TriggerEvent("billing_ui:activateBillingMode")
```
