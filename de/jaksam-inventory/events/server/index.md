Das Inventarsystem löst verschiedene Events aus, wenn Items hinzugefügt, entfernt oder übertragen werden. Du kannst auf diese Events hören, um eigene Logik zu implementieren.

| Event | Beschreibung |
| --- | --- |
| [Inventory item added](/de/jaksam-inventory/events/server/on-inventory-item-added) | Wird ausgelöst, wenn ein Item erfolgreich zu einem Inventar hinzugefügt wurde |
| [Inventory item removed](/de/jaksam-inventory/events/server/on-inventory-item-removed) | Wird ausgelöst, wenn ein Item erfolgreich aus einem Inventar entfernt wurde |
| [Inventory item transferred](/de/jaksam-inventory/events/server/on-inventory-item-transferred) | Wird ausgelöst, wenn ein Item erfolgreich zwischen Inventaren übertragen wurde |
