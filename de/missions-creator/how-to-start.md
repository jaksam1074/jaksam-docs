Ein paar Konzepte, die für den Einstieg ins Script nützlich sind.

### Was ist eine Mission?

Eine Mission ist eine Gruppe von Stages. Sind alle Stages abgeschlossen, ist die Mission beendet.

### Was ist eine Stage?

Eine Stage ist eine Gruppe von Tasks und Actions.

### Was ist ein Task?

Tasks sind Ziele, die Spieler erfüllen müssen, um in der Mission fortzuschreiten. Sind alle Pflicht-Tasks einer Stage abgeschlossen, startet die Mission die nächste Stage.

Ein paar Beispiele für Tasks:

- **Zu Koordinaten gehen**: Spieler müssen die Koordinaten erreichen, um diesen Task zu bestehen.
- **Fahrzeug ausliefern**: Spieler müssen ein Fahrzeug zu einer von dir festgelegten Zone bringen.

### Was ist eine Action?

Actions sind das, was das Script während deiner Mission automatisch tut, um alles flüssig und spannend zu gestalten, zum Beispiel:

- Entitäten spawnen
- Items geben
- Polizei alarmieren

Es gibt 2 Arten von Actions:

- **Starting Actions**: Dinge, die passieren, sobald eine neue Stage beginnt.
- **Ending Actions**: Dinge, die passieren, sobald eine Stage endet.

## Abschließender Tipp

Willst du sehen, wie eine vollständige Mission funktioniert, importiere eine bestehende aus **Nexus**, der Ingame-Funktion von Missions Creator. Nach dem Import kannst du sie bearbeiten, um zu sehen, wie es gemacht wurde.
