Drogenfabriken sind kaufbare Interieurs, in denen Spieler durch einen mehrstufigen Produktionsprozess Drogen herstellen können.

## Funktionen

- **Kauf**: Spieler können eine Fabrik über das Ingame-Menü kaufen. Jede Fabrik hat einen konfigurierten Preis und ein optionales Besitzlimit pro Spieler
- **Interieur**: Jede Fabrik nutzt eine IPL (z.B. Meth-Labor, Koks-Labor)
- **Produktionsstationen**: Fabriken haben Stationen, an denen Spieler Produktionsschritte durchführen (Mischen, Pressen, Gießen). Jeder Schritt verbraucht Eingabe-Items und produziert nach einer konfigurierten Dauer Ausgabe-Items
- **NPC-Arbeiter**: Stationsarbeiter können als Upgrade angeheuert werden, was die Produktionsgeschwindigkeit über konfigurierbare Multiplikatoren erhöht. Jede Station unterstützt mehrere Upgrade-Stufen mit individuellen Kosten
- **Stash**: Jede Fabrik hat einen privaten Stash zur Lagerung von Zutaten und fertigen Produkten
- **Whitelist**: Fabrikbesitzer können andere Spieler whitelisten, um ihnen Zugriff zu gewähren
- **Besucher / Klingel**: Nicht gewhitelistete Spieler können am Fabrikeingang klingeln, und der Besitzer kann den Zutritt gewähren oder verweigern
- **Verkauf**: Besitzer können ihre Fabrik zurückverkaufen

## Konfiguration

Alle Fabrikeinstellungen (Preise, Stationen, Produktionsschritte, Upgrades, Stash-Limits) werden über das Ingame-Menü `/drugscreator` verwaltet.
