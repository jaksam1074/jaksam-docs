The inventory system triggers various events when items are added, removed, or transferred. You can listen to these events to implement custom logic.

| Event | Description |
| --- | --- |
| [Inventory item added](/jaksam-inventory/events/server/on-inventory-item-added) | Triggered when an item is successfully added to an inventory |
| [Inventory item removed](/jaksam-inventory/events/server/on-inventory-item-removed) | Triggered when an item is successfully removed from an inventory |
| [Inventory item transferred](/jaksam-inventory/events/server/on-inventory-item-transferred) | Triggered when an item is successfully transferred between inventories |
