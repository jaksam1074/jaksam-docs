## Cómo usar esta documentación

La mayoría de los scripts tienen una carpeta llamada **integrations**, donde puedes añadir tu código de integración al final de los archivos. Así que casi siempre solo necesitarás añadir tu código dentro de estos archivos, no en otros scripts.

<Tip>
  Lee los comentarios con atención, explican todo lo que necesitas justo encima de las líneas de código.
</Tip>

### Archivos de integración

<CardGroup cols={3}>
  <Card title="cl_integrations.lua" icon="laptop">
    Código para scripts del **lado del cliente**, por ejemplo para reemplazar notificaciones o la barra de progreso. Normalmente aquí insertas el código de la categoría `Client` de la documentación.
  </Card>

  <Card title="sh_integrations.lua" icon="arrows-left-right">
    Código que se ejecuta **tanto en el cliente como en el servidor**, normalmente nombres de scripts externos, para que puedas editarlos si tu servidor usa un nombre distinto al predeterminado.
  </Card>

  <Card title="sv_integrations.lua" icon="server">
    Código para scripts del **lado del servidor**. Normalmente aquí insertas el código de la categoría `Server` de la documentación.
  </Card>
</CardGroup>

<Info>
  Si buscas una opción que no encuentras en la configuración normal, probablemente esté dentro de los archivos de integración.
</Info>
