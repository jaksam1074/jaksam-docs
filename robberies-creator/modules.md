Modules are an easy way for Robberies Creator to replace certain default features (progress bar, dispatch, logs).

To choose an existing module, open the `/robberiescreator` menu, go to settings, and choose it. That's it.

### How to create a custom module?

Creating a module is extremely easy:

<Steps>
  <Step title="Navigate to the modules folder">
    Go to the `robberies_creator/_modules` folder.
  </Step>
  <Step title="Choose the module type">
    Choose the module type you want to create (logs, progress bar, dispatch, etc.).
  </Step>
  <Step title="Duplicate an existing module">
    Duplicate an existing module and use it as a template.
  </Step>
</Steps>
